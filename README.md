# CallMeBot API

A minimal custom integration for Home Assistant, distributed through HACS.

The integration currently provides no configuration options, services, or entities.

## Installation

1. In HACS, add this repository as a custom repository with the type **Integration**.
2. Download **CallMeBot API**.
3. Restart Home Assistant.
4. Go to **Settings → Devices & services → Add integration**.
5. Search for and select **CallMeBot API**.
